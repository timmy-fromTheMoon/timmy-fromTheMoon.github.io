Transcribe on your own computer.

TranscriptionSuite turns your recordings into text using an engine installed on your PC or Mac. A small local connector lets Summit send audio to that engine. Each person runs their own copy.

You will need TranscriptionSuite, its model download, and Python 3.10 or newer for the connector. Setup is a one-time task; keep the engine and connector open while transcribing.

  1. Install TranscriptionSuite

    Follow the official installation instructions for your computer, then download the Dashboard from the official releases page.

    Windows, Linux, and Intel Macs use Docker or Podman. Apple Silicon Macs can use the bundled Metal app. The official guide covers the prerequisites, including FFmpeg on Mac for compressed audio.

  2. Start the local Whisper engine

    Open TranscriptionSuite’s Server tab. Select CPU Only and a Faster-Whisper (WhisperX) model. On an Apple Silicon Mac, use Metal and MLX Whisper.

    Start the local server on its default HTTP port 9786 and wait for the model to finish downloading and loading. Start with a small multilingual Whisper model if you use a CPU. Larger models take more time and memory.

  3. Launch the Summit connector

    Install Python 3.10 or newer if needed. On Windows, select “Add Python to PATH” during installation. The connector needs no extra Python packages.

    Download local connector

    Extract the ZIP into a folder. On Windows, open start-windows.cmd. On Mac, open start-mac.command; if it cannot launch, open Terminal in that folder and run sh start-mac.command. On Linux, run sh start-linux.sh.

    Keep the connector window open. It displays your pairing code and the address http://127.0.0.1:4787.

  4. Pair it with Summit

    Return to Summit and open Settings → Transcription. Choose TranscriptionSuite, enter the connector address, paste the pairing code from its window, and run the connection check. Save your settings.

    Allow Summit’s local-network permission if your browser asks. You can now upload or record audio in Summit and transcribe it on this computer. After restarting the connector, paste its new pairing code into Settings.

Connection or transcription trouble

Engine not running: start the local server in TranscriptionSuite on port 9786. Engine not ready: wait for the model to load. Pairing required: paste the current code from the connector window.

Browser cannot connect: keep the connector open, verify its address, and allow local-network access for Summit. Port already in use: close the other connector window and restart it.

CPU processing is slow: select a smaller Whisper model or use shorter recordings. Audio files can be up to 128 MiB. Keep both local apps running until processing finishes.

Where audio goes and what is included

The connector listens only on this computer’s loopback address. Summit sends the audio to that connector, which forwards it to your own local TranscriptionSuite engine. There is no shared or hosted transcription service.

The download contains Summit’s independent connector and launch scripts. It includes no engine, model weights, or pairing code. Install the engine separately from the official project. Temporary uploads are removed when the request finishes.

TranscriptionSuite is a separate upstream project under GNU GPL v3. Its engine code is not bundled with Summit. Model licenses and installation requirements are documented upstream.
